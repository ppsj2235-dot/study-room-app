# 공부방 홈페이지

학부모가 발급받은 아이디/비밀번호로 로그인하는 홈페이지 + 관리자가 매달 알림장을
디자인은 그대로 유지한 채 내용만 바꿔서 만들고 이미지로 다운로드하는 기능까지 들어있습니다.
학부모별 학습 평가표 업로드는 다음 단계에서 이어서 추가할 예정입니다.

## 지금 되는 것

- 관리자 로그인 → 관리자 대시보드
  - 학부모 계정(아이디/비밀번호/학부모 이름/학생 이름) 발급, 목록 확인, 비밀번호 재설정, 삭제
  - **월간 알림장 관리**
    - 연도/월을 고르면 이전 알림장 내용(공지사항 형식 제외한 고정 항목들)을 이어받은 초안이 자동 생성
    - **달력은 매달 자동 생성**됩니다. 월·화·수·목은 운영일(초록), 금·토·일과 대한민국 공휴일(대체공휴일 포함)은
      휴무일(빨강)로 자동 표시되고, 실제와 다르면 "추가 휴무일 / 추가 운영일"로 특정 날짜만 보정할 수 있습니다.
    - 공지사항, 수강료 납부 안내(+ QR 이미지 업로드), 성장 포인트, 학습 TIP, 가정에서 부탁드립니다,
      문의 및 안내 → 모두 홈페이지에서 텍스트만 수정
    - 원장 한마디 / 이번 달 명언 → 계절·시기에 맞춰 자동으로 문구가 채워지고, "다른 문구 추천받기"
      버튼으로 다시 뽑거나 직접 수정 가능
    - 디자인(색상, 배치, 캐릭터 삽화 등)은 고정되어 있어 내용만 바꿔도 항상 같은 톤의 알림장이 나옵니다
    - **이미지로 다운로드** 버튼으로 PNG 파일을 바로 받아 카카오톡 등으로 학부모에게 전달할 수 있습니다
  - **성적 관리 (관리자 전용)**
    - 중간고사·기말고사·월말고사 점수를 학생(학부모 계정)별로 등록/수정/삭제
    - 과목은 기본값이 "수학"이지만, 방학 때 국어 특강처럼 다른 과목도 직접 입력해서 등록 가능
    - 학생별로 필터링해서 볼 수 있음
    - **학부모는 이 화면에 접근할 수 없습니다** (관리자만 등록 가능, 학부모 화면에서 점수를 보여주는 기능은 다음 단계)
- 학부모 로그인 → 학부모 페이지
  - **성적**: 관리자가 등록한 우리 아이 점수를 과목별 추이 그래프 + 전체 기록 표로 확인 (관리자가 등록해야만 보임)
  - 학습 평가표(이미지)는 아직 "준비 중" 안내만 표시, 다음 단계에서 연결 예정
- 로그인하지 않은 사용자는 무조건 로그인 화면으로 이동, 관리자가 아닌 사람은 관리자 전용 페이지 접근 차단(403)

뒤에는 자동으로는 안 바뀌니 실제로는 관리자 로그인 후 별도 "내 비밀번호 변경" 기능이 필요하시면
다음 단계에서 추가해드릴게요.)

## 알림장 자동 생성에 대한 참고

- **공휴일 데이터**: 2025~2028년 기준으로 정리해두었고, 대체공휴일도 규칙에 따라 자동 계산됩니다
  (`holidays_kr.py`). 다만 몇 년 뒤 법이 바뀌거나 정부 발표와 다를 수 있으니, 실제 공휴일과 다르면
  알림장 편집 화면의 "추가 휴무일 / 추가 운영일"로 그 달만 바로 고칠 수 있습니다.
- **원장 한마디 / 이번 달 명언**: 인터넷 연결 없이도 항상 다르게 나오도록 월별/문구별로 미리 준비된
  문장 목록에서 자동으로 골라줍니다(`content_bank.py`). 문구 목록을 늘리거나 문체를 바꾸고 싶으시면
  말씀해주시면 계속 다듬어드릴 수 있어요.
- **이미지 다운로드**: 서버에서 Playwright(자동화 브라우저)로 알림장 화면을 그대로 캡처해서
  고화질 PNG로 만들어줍니다. Render 등 배포 환경에도 Playwright가 설치되도록
  `requirements.txt`/빌드 설정이 되어 있어야 하는데, 아래 배포 가이드에 반영해두었습니다.

## 기술 스택

Python + Flask + SQLite(내장 파일 DB) + Playwright(알림장 이미지 캡처용).
데이터베이스 관련 코드는 `db.py`, `models.py`, `models_newsletter.py`에 모아두었습니다.

## 로컬에서 실행해보기

```bash
# 1) 필요한 패키지 설치
pip install -r requirements.txt
python3 -m playwright install chromium   # 알림장 이미지 다운로드 기능에 필요

# 2) 환경변수 설정
cp .env.example .env
# .env 파일을 열어 SECRET_KEY 등을 원하는 값으로 바꿔주세요 (관리자 계정은 기본값이 이미 들어있습니다)

# 3) 실행
python3 app.py
```

브라우저에서 `http://localhost:5000` 접속 → 위 관리자 아이디/비밀번호로 로그인.

## 무료로 배포하기 (Render 기준, 추천)

1. 이 폴더를 GitHub 저장소로 올립니다.
2. [render.com](https://render.com)에서 GitHub 계정으로 가입/로그인
3. **New +** → **Web Service** 선택 → 방금 만든 GitHub 저장소 선택
4. 아래와 같이 설정
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt && python -m playwright install --with-deps chromium`
   - **Start Command**: `gunicorn app:app --timeout 60`
   - **Instance Type**: Free
5. **Environment Variables**에 `.env.example`에 있는 항목들을 하나씩 등록
   - `SECRET_KEY` : 아무 긴 임의 문자열 (예: `python3 -c "import secrets; print(secrets.token_hex(32))"` 실행 결과)
   - `ACADEMY_NAME` : 공부방 이름
   - `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ADMIN_NAME` : 선생님 로그인 계정 (기본값 그대로 써도 됨)
   - `SESSION_COOKIE_SECURE` : `1`
6. **Create Web Service** 클릭 → 몇 분 뒤 `https://xxxx.onrender.com` 같은 주소가 발급됩니다.

> Playwright 설치(`--with-deps`)는 시간이 좀 걸리고, Render 무료 요금제 빌드 시간 제한에 걸릴 수 있습니다.
> 만약 빌드가 실패하면 알려주세요 — 이미지 다운로드 없이 화면 미리보기만 쓰거나, 더 가벼운 캡처 방식으로
> 바꿔드릴 수 있습니다.

### ⚠️ 데이터 보관 관련 중요 안내

Render 무료 요금제는 재배포되거나 오래 사용이 없으면 디스크 내용이 초기화될 수 있어서, 지금 구조로는
**학부모 계정 / 알림장 내용 / 업로드한 QR 이미지가 사라질 수 있습니다.** 테스트 단계에는 문제없지만,
실제 운영 전에는 아래 중 하나로 업그레이드하는 걸 권장드립니다.

- Render의 **Persistent Disk**(유료, 월 1달러대부터) 연결
- 또는 무료 PostgreSQL(Supabase, Neon, Render Postgres 무료 플랜 등)로 데이터베이스 자체를 교체

학습 평가표 업로드 기능을 만들 때(다음 단계) 이 부분도 함께 정리해드리겠습니다.

## 다음 단계 (예정)

1. 관리자가 학부모별로 학습 평가표(성적표 이미지) 파일을 업로드하고, 해당 학부모만 로그인해서 확인
2. 데이터/파일을 재배포해도 사라지지 않도록 영구 저장소로 업그레이드
3. (원하시면) 관리자 비밀번호를 화면에서 직접 바꾸는 기능
